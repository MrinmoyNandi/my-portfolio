## Overview

AI Code Crafter is under development. This page describes what it is **meant** to do. Working capabilities will be listed here once they are verified.

## The problem

Large or AI-generated repositories are hard to understand file by file. A visual map of the structure would make them easier to inspect.

## Intended capabilities

None of these are working features yet:

- Show which files depend on which other files.
- Show which files or functions call other code.
- Show how the parts of a repository fit into the overall architecture, as a mind map or graph.

## Stack

- JavaScript
- Supabase
- An OpenAI model via the API

## Status

In development. Current functionality will be documented separately from planned features as it lands.
